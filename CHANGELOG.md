# Changelog

## 1.0.1 - 2026-09-13

- Marked player-attributed broadcasts as vanilla announcements for E33Chat compatibility.
- Joined clickable controls to their matching alert and removed the stray parsed period.
- Made countdown start adjustable and changed the sequence to clear instead of displaying `1`.
- Corrected alert-setting Back navigation and added current values to menu titles.
- Added single/double Item Pond layouts and configurable page counts from 1 to 10.
- Kept filtered stacks physically separate from normal Pond storage and protected from washing.

## 0.1.1 - 2026-09-09

- Rebranded the project and internal mod identity as Clean Bill - Item Cleaner.
- Added `/cb` and `/cleanbill` while retaining the previous command aliases and world/config compatibility.
- Rebuilt configuration around categorized vanilla chest menus and removed direct setting commands.
- Added detailed tooltips, per-setting reset icons, private message/sound previews, and chat-captured message editing.
- Added legacy-plus-hex color parsing and a softer pastel interface palette.
- Redesigned the Item Pond as take-only storage with a bottom control toolbar and protected filtered inventory.
- Added public, source-attributed operational and status announcements with compact action-bar variants.
- Changed the default and reset alert sound to jukebox.

## 1.0.0 - 2026-09-09

- Initial public release for Minecraft 1.21.1 and NeoForge 21.1.248+.
- Added restart-safe cleanup timers, announcements, sounds, clickable controls, and minimum-age protection.
- Added unloaded-chunk timestamps without force-loading chunks.
- Added the persistent three-page Item Pond and operator configuration GUI.
